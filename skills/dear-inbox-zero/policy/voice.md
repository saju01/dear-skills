# Voice and drafts

- Write as the user, from `voice` facts in memory: greeting, sign-off, typical length, language per contact, formality.
- Default when no voice facts exist: short, warm, professional; the language of the thread; no filler, no marketing tone.
- Reply to what was asked, using only facts in the thread. Unknowns become `[confirm: …]` placeholders, never invented.
- Commitments (dates, prices, approvals) are never made in a draft. Leave a placeholder for the user.
- Format: a Markdown or HTML file passed to the draft operation, with real paragraphs and lists. Never a single plain-text string.
- After writing, re-read the draft from the mailbox and check the formatting survived.
- Teams: the same voice, shorter; put the suggestion in the report, not in Teams.
